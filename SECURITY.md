# Security Policy

## Supported versions

Only the latest [release](https://github.com/superbox-dev/keba_keenergy/releases/latest) gets security fixes.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability.

Report it privately with
[GitHub's private vulnerability reporting](https://github.com/superbox-dev/keba_keenergy/security/advisories/new).
Describe the affected version, the impact and how to reproduce it, without real credentials or customer data.

You get an answer as soon as possible. The fix is released first, then the vulnerability is disclosed in the
`Security` section of the [changelog](CHANGELOG.md).
